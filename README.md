# Лисёнок и огненный жёлудь 🦊🔥

Браузерный платформер, целиком написанный нейросетью **Claude Fable 5.2** в [Syntx](https://syntx.ai/welcome/8cfJeb4X) по подробному ТЗ.
4 сообщения, 1465 строк, один HTML-файл без картинок и библиотек — вся графика и звук сделаны кодом.

## ▶ Играть

**https://sashatchersunov6-rgb.github.io/lisenok-game/**

## Управление

| Действие | Клавиши |
|---|---|
| Бег влево / вправо | ← → или A / D |
| Прыжок | ↑, W или пробел |
| Ускорение | Shift |
| Огонёк (с огненным цветком) | X или F |
| Пауза / звук / заново | P / M / R |

На телефоне — экранные кнопки.
